FONTES E QUALIDADE

Como interpretar estes dados

01

Resultados, não previsões

Os percentuais de candidatura usam exclusivamente votos válidos registrados no primeiro turno da eleição selecionada. As opções de candidatura são específicas de cada ano.

02

Compatibilidade geográfica

Municípios são identificados pelo código IBGE de sete dígitos, reconciliado com o TSE. O mapa de 2022 serve como referência territorial de exibição para os dois anos.

03

Exceções transparentes

Um município do Amazonas possui uma exceção de 84 eleitores aptos no denominador de 2022; a interface sinaliza essa limitação. Não inferimos intenção de voto de indivíduos.
